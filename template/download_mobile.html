IITC F-Droid repo

F-Droid is an installable catalogue of FOSS apps for Android. Unlike the official F-Droid repository, the IITC F-Droid repo also provides beta builds and delivers updates instantly. It hosts both IITC Mobile and IITC Prime.

To add this repository to your F-Droid client, scan the QR code (click it to enlarge) or use this URL:

https://static.iitc.app/fdroid/repo

If you would like to manually verify the fingerprint (SHA-256) of the repository signing key, here it is:
B7 89 9F B6 61 89 6B 37 4D 10 03 A3 1B A1 C5 41 39 A9 EF DC 6B 9D 53 A7 0F 51 80 76 8E F1 97 B9

IITC Mobile

android official
  • Android (5.0+): Google Play (release & beta), official F-Droid repo (release) or the IITC F-Droid repo (release & beta)
  • Direct .apk: release (v{{ release_iitc_version }}), beta (v{{ beta_iitc_version }}) — archives: release, beta

Google Play, the official F-Droid repo, and the IITC F-Droid repo / .apk are each signed with a different key, so you can't update across sources. To switch, uninstall the current version first, then install the new one — use the backup/restore plugin to migrate your data.
Source code: github.com/IITC-CE/ingress-intel-total-conversion

IITC Prime

android iOS official
  • Android (7.0+): Google Play (release & beta) or the IITC F-Droid repo (release & beta)
  • iOS (13+): TestFlight (beta)

Android builds share the same signing key on Google Play and the IITC F-Droid repo, so updates install over each other.
Source code: github.com/IITC-CE/IITC-Prime
